# Сверки, первичные документы, банковская выписка

Содержание: первичные документы · требования к документу · акт сверки · сверка банковской выписки · типичные ошибки

## Первичные документы

Первичка подтверждает, что операция была. Без неё налоговая вправе снять расход (на УСН «доходы минус расходы», ОСНО) и доначислить налог.

| Документ | Когда нужен |
|---|---|
| Договор | Основание отношений. Для услуг и крупных сделок желателен письменный. |
| Счёт на оплату | Не первичка, а предложение оплатить; нужен как основание платежа. |
| Акт выполненных работ (услуг) | Подтверждает оказание услуги. Без акта расход по услуге не принимается. |
| Товарная накладная (ТОРГ-12) | Передача товара. |
| УПД | Универсальный передаточный документ: заменяет накладную/акт и счёт-фактуру. |
| Счёт-фактура | Нужен для вычета НДС у покупателя; у продавца-плательщика НДС обязателен. |
| Кассовый чек / БСО | Подтверждает расчёт наличными или картой. |
| Авансовый отчёт | Расходы подотчётного лица с приложенными чеками. |
| Платёжное поручение / выписка | Подтверждает оплату, но не заменяет акт или накладную. |

## Что проверять в документе

Реквизиты по ст. 9 закона 402-ФЗ:
1. Наименование и дата составления.
2. Наименование организации/ИП, ИНН и подпись ответственных лиц.
3. Содержание операции, измерители (количество, сумма).
4. Согласованные цена, сумма и ставка НДС (если плательщик).
5. Реквизиты контрагента совпадают с договором и ЕГРЮЛ/ЕГРИП.

Дата документа должна совпадать с датой операции; «прошлые» акты и накладные — повод для вопроса налоговой.

## Акт сверки взаиморасчётов

Акт сверки фиксирует, сколько стороны должны друг другу на дату. Он не обязателен по закону, но помогает при спорах и приостанавливает срок давности, если подписан.

**Как составить**
1. Выгрузи данные по контрагенту: договор, период, начальное сальдо.
2. Запиши обороты по датам: отгрузки/оказание услуг (увеличивают долг покупателя) и оплаты (уменьшают).
3. Выведи конечное сальдо: кто и кому должен.
4. Подготовь акт в двух экземплярах: данные с обеих сторон.

**Если данные не сходятся**
- Проверь, не пропущены ли документы (акты, УПД, возвраты).
- Проверь даты: платёж мог пройти в один день, а отразиться в другой.
- Проверь суммы: курсовые разницы, НДС, округление.
- Проверь, не отнесён ли платёж к другому договору.
- Найденные расхождения выпиши списком: дата, документ, сумма у меня, сумма у контрагента, разница.

Шаблон акта в текстовом виде:

```
АКТ СВЕРКИ ВЗАИМНЫХ РАСЧЁТОВ
между <Организация 1> и <Организация 2>
за период с <дата> по <дата> по договору <№ ... от ...>

Сальдо на <дата начала>: в пользу <кого>, <сумма> руб.
| Дата | Документ | Дебет (отгрузка) | Кредит (оплата) |
...
Сальдо на <дата конца>: в пользу <кого>, <сумма> руб.

От <Организация 1>: ___ / ___        От <Организация 2>: ___ / ___
```

## Сверка банковской выписки

Цель: каждая строка выписки должна иметь документ-основание и быть отражена в учёте.

1. Сопоставь каждое поступление с договором/счётом и покупателем. Нет основания — уточни у клиента, чьи деньги.
2. Сопоставь каждое списание с первичкой. Нет акта/накладной — запроси у поставщика.
3. Отдели операции, не связанные с услугами: комиссии банка, проценты, возвраты, налоги.
4. Проверь остаток: начальный остаток + поступления − списания = конечный остаток, как в выписке.
5. Для ИП на УСН: отметь, какие поступления являются доходом (поступления от клиентов), а какие нет (возврат, собственные средства, займ).

Не всякое поступление — доход: взнос собственных средств, заём, возврат ошибочного платежа в доходы на УСН не включаются.

## Типичные ошибки

- Платёж есть, акта нет → расход не принимается.
- Дата акта позже даты платежа → пересмотреть признание расхода.
- Один платёж за несколько договоров → разнести по назначениям.
- Аванс принят как доход без отражения обязательства (у плательщика НДС — без НДС с аванса).
- Личные расходы ИП проведены как бизнес-расходы.
- Расчёты с контрагентом через наличные выше лимита (расчёты между юрлицами/ИП наличными по одному договору — до 100 000 руб.).
- Документ подписан неуполномоченным лицом или без расшифровки.
